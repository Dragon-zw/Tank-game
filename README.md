## 📖 项目简介

这是一款经典的坦克大战游戏，玩家需要控制坦克保护基地，消灭所有敌方坦克。游戏采用纯前端技术实现，无需任何后端服务，支持现代浏览器。

### ✨ 游戏特性

- 🎯 **经典玩法**：保护基地，消灭所有敌方坦克
- 🤖 **智能 AI**：敌方坦克具有自主移动和攻击能力
- 💥 **视觉效果**：爆炸动画、粒子特效、流畅渲染
- 🎨 **现代 UI**：深色主题、渐变效果、响应式设计
- 🏆 **关卡系统**：支持多关卡，难度递增
- ❤️ **生命系统**：3 条生命，被击中后可重生

### 🎮 游戏元素

| 元素 | 说明 |
|------|------|
| 🟢 玩家坦克 | 绿色坦克，通过键盘控制 |
| 🔴 敌方坦克 | 红色坦克，具有 AI 逻辑 |
| 🟤 砖墙 | 可被子弹摧毁的障碍物 |
| ⚫ 钢墙 | 不可摧毁的障碍物 |
| 🏰 基地 | 需要保护的目标 |

## 🚀 快速开始

### 前置要求

- 现代浏览器（Chrome、Firefox、Edge、Safari）
- Python 3.x（用于启动本地服务器）或其他 HTTP 服务器

### 启动游戏

#### 方法一：使用 Python（推荐）

```bash
# 进入项目目录
cd tank-game

# 启动 HTTP 服务器
python3 -m http.server 8000
```

#### 方法二：使用 Node.js

```bash
# 安装 http-server（首次使用）
npm install -g http-server

# 启动服务器
http-server -p 8000
```

#### 方法三：使用 PHP

```bash
php -S localhost:8000
```

### 访问游戏

启动服务器后，在浏览器中访问：

```
http://localhost:8000
```

### 关闭程序

在启动服务器的终端窗口中按 `Ctrl + C` 即可停止服务器。

```bash
# 按下组合键
Ctrl + C

# 或者在 macOS 上
Cmd + C
```

### 游戏规则

1. **目标**：消灭所有敌方坦克，保护基地不被摧毁
2. **生命**：玩家拥有 3 条生命，被击中后会扣除一条生命
3. **得分**：每消灭一个敌方坦克获得 100 分
4. **关卡**：完成当前关卡后自动进入下一关，敌人数量增加
5. **失败条件**：
   - 玩家生命值耗尽
   - 基地被敌方子弹击中

## 🐛 故障排除

### 游戏无法启动

**问题**：访问 `http://localhost:8000` 显示无法连接

**解决方案**：

1. 确认 HTTP 服务器已启动
2. 检查端口 8000 是否被占用
3. 尝试使用其他端口：`python3 -m http.server 8080`

### 游戏画面不显示

**问题**：页面加载但游戏画面是黑色的

**解决方案**：

1. 打开浏览器开发者工具（F12）查看控制台错误
2. 确认所有 JavaScript 文件都已正确加载
3. 刷新页面（Ctrl + F5 或 Cmd + Shift + R）

### 键盘控制无响应

**问题**：按键后坦克不移动

**解决方案**：

1. 点击游戏画布区域确保焦点在游戏上
2. 检查是否在暂停状态（按 P 继续）
3. 确认游戏已经开始（点击"开始游戏"按钮）
